# Demo script (about 2 minutes 30)

The recorded video is produced by `scripts/demo/record-demo.mjs` against the live site: the "person" is a synthesized voice injected into the microphone and labelled as simulated on screen; Stay's replies are the real AssemblyAI audio. If you present live instead, follow the same beats with your own voice.

| Time | Show | Say |
|---|---|---|
| 0:00 | Title card, then the landing page | "Stay is a voice companion for adults with ADHD. It helps you start the thing you have been avoiding, and it does not talk over your pauses." |
| 0:15 | Type "overwhelmed", "stuck", "taxes" into the orb box | "Type or say what is in the way, and the dots become it. Overwhelmed is a tangle. Stuck is a staircase with one dot on the first step." |
| 0:35 | Open the app, tap the orb, speak the first line | "Um, I keep putting off replying to my landlord about the renewal." Replies start about a second after you stop. |
| 0:55 | Say a sentence with a 2.3 s hole in it | "I need to, um, send that email, and, uh..." (pause) "...and I keep thinking about how to even start it." Stay waits, then answers the finished thought. |
| 1:15 | Ask for too much, then interrupt | "Can you give me a really detailed plan for my whole week." Then, while it talks: "Wait, stop, just one tiny step please." It stops in about half a second. |
| 1:35 | Park a thought | "Park it: I need to call the dentist." Confirmed in about 1.3 s; open Parked thoughts to show it. |
| 1:50 | Today card, Brain dump sheet, Routine sheet | "Everything on your mind, in any order. Stay picks one thing to start, a few for today, and the rest for later. No overdue, no guilt." |
| 2:10 | Reply-speed readout, then the README table | "Measured with a simulated speaker: about 1.3 seconds against 2.8 for the managed voice it replaced. Not measured: ChatGPT voice or Google live voice." |
| 2:25 | End card with the URL | "Stay. Open source, local-first, built on AssemblyAI." |

## If something goes wrong live

- No microphone permission: type the same lines; the app handles typed turns the same way.
- Voice session fails to start: the app falls back to the managed agent or Quiet Text Mode by itself; say so, do not hide it.
- Shared allowance used up: add your own AssemblyAI key in Settings (this is what the "Your own keys" section is for).
- Never claim a comparison with another product's voice. The honest line is in the README.

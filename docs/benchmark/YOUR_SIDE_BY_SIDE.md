# Your side-by-side: Stay and ChatGPT Live, same 20 lines

Run this yourself (Stay does not sign in to other people's products). Same laptop, same headphones, same room, same day.

1. Start a screen recording with sound (Windows: Win + Alt + R, or OBS).
2. Open ChatGPT and press the voice button. Read the 20 lines below in order, waiting for each reply. Where a line says pause, really pause; where it says talk over it, start the next words while it is still speaking.
3. Stop. Start a new recording. Open https://stay-two-swart.vercel.app/app/today, press Talk, and read the same 20 lines.
4. Fill in the score sheet for both (1 = yes, 0 = no). What each scenario is checking is in the third column; the full rules are in `docs/benchmark/HEAD_TO_HEAD.md`.
5. Send me the two recordings. I count reply times frame by frame from the video and write up the result exactly as measured, wins and losses side by side.
